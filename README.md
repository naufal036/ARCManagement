## Deskripsi Tugas
*1. Bagian Autentikasi, Hak Akses & Template Dasar*
Tugas: Mengatur sistem Login/Register, membatasi hak akses (multi-role: Direktur, Admin, Pengawas, Staf), mencatat riwayat aktivitas, dan memasang template layout utama (navbar, sidebar, footer) yang bakal dipakai sama semua anggota lain.

*2. Bagian Master Data & Registrasi Proyek*
Tugas: Membuat CRUD (tambah, lihat, edit, hapus) untuk data Klien, kategori Jenis Pekerjaan, dan Data Induk Proyek. Termasuk merancang form input proyek baru dan menampilkan daftarnya.

*3. Bagian Kontrak & Penugasan Tim*
Tugas: Membangun fitur untuk mengelola data Kontrak dan Adendum (perubahan kontrak), serta membuat halaman agar Admin bisa menugaskan staf/karyawan ke proyek tertentu beserta tenggat waktu pekerjaannya.

*4. Bagian Manajemen & Arsip Dokumen*
Tugas: Fokus di pengelolaan file. Membuat fitur upload, download, dan pencarian dokumen proyek, mengelompokkan kategori dokumen, serta mengelola pencatatan revisi kalau ada file yang diperbarui.

*5. Bagian Progres & Pelaporan*
Tugas: Membuat tampilan untuk mencatat persentase progres harian/mingguan proyek, membuat tombol setuju/tolak dokumen untuk Direktur/Klien, dan menyatukan data-data tersebut ke dalam halaman cetak laporan akhir.
